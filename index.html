Хозтовары

Интернет-магазин хозяйственных товаров «под ключ» — от идеи до запуска с интеграциями
🛒

Полный функционал

Каталог, корзина, личный кабинет, админ-панель, онлайн-оплата, расчёт доставки.

🔌

Интеграции

Evotor (онлайн-кассы), Komtet (логистика), подготовка чеков, синхронизация товаров.

🧠

Современный стек

Laravel 11, MySQL, Tailwind CSS, Livewire (или Blade), готов к масштабированию.

⚙️ Технологии проекта:

PHP 8.2 Laravel 11 MySQL Blade Tailwind CSS jQuery Git Evotor API Komtet API
